Reference
=========

These pages describe midi2's public interface precisely, one sub-library at a time. The
types and functions in any namespace named ``details``, and the on-the-wire layouts in the
MIDI-CI namespaces named ``packed``, are implementation details. They may change without
notice, and you should not use them.
